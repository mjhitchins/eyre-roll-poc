Methodology. Offence type and verdict are extracted by Latin keyword matching on Maitland’s 1884 edition (public domain; Internet Archive: crowncountyplea00glouuoft). Manuscript images (AALT JUST 1/271) were transcribed with Kraken 7 + CATMuS Medieval model; character error rate on membrane m24 was 95.7 % — an expected baseline for off-the-shelf HTR on 13th-century English court hand without fine-tuning. A high error rate is an honest and reportable finding; this page presents derived metrics from the ground-truth edition, not from the raw transcript. Source code: github.com/mjhitchins/eyre-roll-poc.
